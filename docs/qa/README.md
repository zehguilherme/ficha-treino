# QA — Ficha de Treino

## Áreas

- `EXE`: busca e adição de exercícios.

## Execução local

- Backend: `cd backend; npm run dev` em `http://localhost:3001`.
- Frontend: `cd frontend; npm run dev` em `http://localhost:3000`.
- Entrada: usuário autenticado → `/treinos/<dia>/adicionar-exercicio`.

Screenshots de evidência ficam em `docs/qa/evidence/` e não são versionados.
